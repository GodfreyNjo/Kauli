The Kauli API

Send audio or video to Kauli from your own software and get transcripts, subtitles, translations and dubbing back, in the same {{ language_total }} languages as the website. The API runs the same checks and prices as the dashboard, so an API order costs exactly what the same order costs on the site.

Quick start

  1. Sign in and open Settings, then API key and Generate API key. The key is shown once; keep it secret. (Team owners only.)
  2. Send it as a bearer token on every call: Authorization: Bearer kauli_live_...
  3. Create an order, then poll it (or use a webhook) until ready is true.
curl -X POST {{ base }}/api/v1/orders \
  -H "Authorization: Bearer $KAULI_API_KEY" \
  -F "audio=@interview.mp3" \
  -F "source_lang=en" \
  -F "service_level=transcribe"

Base URL and limits

{{ base }}/api/v1. All responses are JSON. Requests are limited to 120 per minute per IP; uploads up to 2 GB per file; order creation is limited per account to protect processing costs.

Create an order

POST /api/v1/orders (multipart form)

FieldDescription
audioThe audio or video file. Send this or url.
urlA YouTube link to transcribe instead of uploading a file.
source_langLanguage spoken in the file, e.g. en, sw, ki, fr. See GET /api/v1/languages.
target_langFor translation or dubbing. Defaults to the source language for transcription, otherwise en.
service_leveltranscribe (default), translate or dub.
review_tierai (Instant AI, default) or human (reviewed by an editor; Swahili, Kikuyu and English only).
idempotency_keyOptional. Retrying with the same key returns the same order instead of creating another. The Idempotency-Key header works too.
folder_name, notesOptional. A folder to file the order under, and instructions for the editor.

Responses:

  • 201: the order was created and is processing.
  • 402 with payment_required: true and a payment_url: the order is held until it is paid. Nothing runs and nothing downloads before payment. 402 with error: "verification_required" means the one-time $1 card check (credited to your account) is needed before free minutes apply.
  • 400 with {"error": "..."}: the request broke a rule, for example a language that is only available as Instant AI.
  • 401 missing or wrong key. 429 rate limited.

Get or list orders

GET /api/v1/orders/{id} and GET /api/v1/orders?limit=25

When an order is paid and ready, deliverables holds signed download links that need no login and expire after 7 days: txt and docx (transcript), transcript (timed SRT in the source language) and, depending on what the order bought, srt, vtt, audio, burned and dubbed. Orders that only used free minutes are previews and have no downloads.

Languages

GET /api/v1/languages needs no key and lists every code with what it supports: transcription, translation as a target, human review and dubbing.

Webhooks

Add a webhook URL in Settings and Kauli sends a POST with {"event": "order.ready", "order": {...}} when an order is delivered. The body is signed so you can verify it came from Kauli: the X-Kauli-Signature header is sha256= plus the HMAC-SHA256 of {timestamp}.{raw body}, using your webhook secret, and X-Kauli-Timestamp carries the timestamp. Webhooks work with Zapier, Make and n8n through their generic webhook triggers.

import hmac, hashlib

def valid(secret: str, timestamp: str, body: bytes, header: str) -> bool:
    expected = "sha256=" + hmac.new(secret.encode(), timestamp.encode() + b"." + body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, header)

Use Kauli from an AI assistant (MCP)

Kauli runs a remote Model Context Protocol server, so an assistant can order and read transcripts for you. It uses the same API key as above, sent as a bearer token.

Endpoint: {{ base }}/mcp (Streamable HTTP). In Claude Code:

claude mcp add --transport http kauli {{ base }}/mcp   --header "Authorization: Bearer $KAULI_API_KEY"

Any other client that lets you set a header on a remote MCP server works the same way:

{
  "mcpServers": {
    "kauli": {
      "type": "http",
      "url": "{{ base }}/mcp",
      "headers": { "Authorization": "Bearer YOUR_KAULI_API_KEY" }
    }
  }
}
ToolWhat it does
kauli_create_orderOrder a transcript, translation or dub from a YouTube link. Same prices and rules as the site; an order that needs payment is held and returns a payment link.
kauli_get_orderCheck one order and get signed download links once it is paid and ready.
kauli_list_ordersYour most recent orders.
kauli_get_transcriptRead the text of a finished, paid order as txt, srt or vtt.
kauli_list_languagesThe language codes Kauli accepts and what each supports.

Ordering spends your money or free minutes, so a good assistant will ask before it orders. The server does not support browser sign-in (OAuth) yet, so connectors that only offer a sign-in button cannot use it; use a client that accepts a header, as above. Files are uploaded through the REST API; the MCP server takes YouTube links.
